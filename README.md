# OpenMail
OpenMail is a free, non-commercial self-hosted SMTP/IMAP/POP Server.

OpenMail was built with Java.

## How to build OpenMail
You must manually build OpenMail for it to run.
### Requirements:
* GitHub Account
* Computer/Server With Java Installed
### Build
* Fork OpenMail by clicking "Fork" below.
